## Part B: Modern Hardened Architecture Spec (Firman Standards)

When rebuilding for production under Firman's engineering standards, apply these upgrades over the 1:1 baseline:

1. **Atomic Row-Level Locks on Code Redemption & Quota Consumption**:
   - Wrap `redeem_codes` redemption and exam attempt quota deductions inside PostgreSQL RPCs using `SELECT ... FOR UPDATE` so concurrent requests cannot double-redeem a single premium code or bypass free-tier limits.
2. **Server-Side Answer Key Isolation**:
   - Never return `correct_answer` or `explanation` in the initial `/exam/[id]` fetch payload; serve a sanitized view (`questions_public`) during the active exam and only grade/reveal `correct_answer` + `explanation` inside a transactional `submit_attempt` RPC / `/result/[id]` RSC query.
3. **Anti-AI-Slop Vector Icon Upgrade**:
   - Replace Unicode emojis (`🔒`, `🧮`, `🛡️`, `🎯`, `😵`) in UI badges, subject cards, and navigation drawers with crisp **Lucide SVG icons** while retaining exact color tokens (`--brand`, `--gold`, `#06C755`).
4. **Thai 3-Byte UTF-8 Safety**:
   - All text truncation helpers (error stack previews, question snippets, CSV/JSON exporters) must slice by Unicode code points (`Array.from(str).slice(0, n).join("")`), never raw UTF-8 byte offsets (`0xE0`).
5. **Edge & Cache Resource Discipline**:
   - Cache static `subjects`, `exam_sets`, and `/articles/*` in memory/CDN (`revalidate = 3600`) to minimize Supabase database reads, while keeping `profiles.active_session` and `/exam/*` real-time.
6. **PWA & Exam Containment**:
   - Add `overscroll-behavior: none` and accidental back-navigation confirmation (`beforeunload` / `popstate` guard) inside `/exam/[id]` so mobile test-takers do not lose answers mid-exam.
